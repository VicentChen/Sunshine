# BUGs
 - 每个Bug都由用户创建, Agent维护. 用户提供Bug描述和复线方法, Agent维护Bug状态, 简短描述Bug成因.
 - 只有用户可以创建Bug, Agent只能维护Bug.

文档模板如下:
```
| 名称 | 状态 | 描述 | 成因 |
| --- | --- | --- | --- |
| Agent维护, 简要概括Bug | Agent维护, ✅已修复/⚠️处理中/❌未修复 | 用户描述 | Agent维护, 简单说明Bug成因 |
```
